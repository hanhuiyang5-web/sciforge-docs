# 功能状态与限制

本页是首版文档基线，不替代每个发布版本的变更日志。状态来自当前源码注册、用户可见入口和真实界面核对。

| 能力 | 状态 | 当前说明 |
| --- | --- | --- |
| 本地工作区与会话 | 已验证 | 可打开项目、新建和继续会话、浏览工作区 |
| Codex Runtime | 已验证 | 默认 Runtime；配置和登录失败会显式报错 |
| Claude Code Runtime | 已验证 | 需要用户显式选择，不与 Codex 静默回退 |
| 模型 API / Coding Plan | 已验证 | 属于模型接入层，与执行 Runtime 分开配置 |
| 只读与工作区写入范围 | 已验证 | 文件范围在 AI 助手设置中管理 |
| 文件预览与变更检查 | 已验证 | 适用格式与远程支持范围存在差异 |
| 定时任务 | 已验证 | 应用需运行，电脑在触发时需保持唤醒 |
| Create Loop | 已验证 | 支持多节点流程；暂停审批状态不跨应用重启保存 |
| Scientific Plotting | 部分可用 | 从可用输入生成并审查图表；需核对 Worker 与依赖 |
| Artifact / Evidence / Dossier | 部分可用 | 入口已注册；内容质量取决于任务是否生成相应记录 |
| Remote SSH | 部分可用 | 可连接远程工作区；复杂 Git、快照和文件操作需逐项验证 |
| Cloud 协作 | 部分可用 | 依赖外部部署、账号、Desktop 注册和协作服务 |
| 扩展中心、Skills 与 MCP | 部分可用 | 对象类型和安全边界不同；部分变更需重启会话 |
| 虚拟细胞预测模型 | 未内置 | 可由用户通过 Agent、脚本和外部环境接入 |
| Slurm/PBS/Kubernetes 自动调度 | 未声明为内置 | 当前教程只描述 Remote SSH 与终端使用外部环境 |

## 状态判定规则

- **已验证**：当前版本存在入口，并完成过代表性真实操作。
- **部分可用**：主路径存在，但受平台、数据、Worker、外部部署或子功能限制。
- **实验性**：适合作为受控集成，不应对普通用户承诺完整闭环。
- **未内置/未发布**：不能从源码注册和真实界面证明为用户功能。

## 文档核验顺序

1. 当前源码是否注册该能力。
2. 是否有用户可见入口。
3. 中文界面中的名称和状态是什么。
4. 操作的 Effect、Approval 和 Scope 是什么。
5. 是否在真实应用中完成过一次端到端验证。
6. 截图是否来自同一版本和同一条任务链。

发现文档与产品不一致时，以当前发布版本的实际行为为准，并在提交问题时附上版本、入口、复现步骤和已脱敏截图。
