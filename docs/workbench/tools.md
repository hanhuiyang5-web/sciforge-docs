# 工作台工具

工具栏中的入口围绕当前工作区和会话展开。打开工具并不等于授权 Agent 执行其中的外部操作。

| 工具 | 适合做什么 | 主要检查点 |
| --- | --- | --- |
| **文件与预览** | 浏览目录、打开文本、表格、图片或科学对象 | 路径、文件版本、是否为原始数据 |
| **终端** | 运行命令、查看日志和长任务状态 | 工作目录、参数、返回码、写入和网络影响 |
| **浏览器** | 打开本地预览或研究资料 | URL、登录状态、下载与外部提交 |
| **Computer Use** | 操作需要图形界面的桌面应用 | 目标应用、系统权限和关键动作确认 |
| **变更** | 审查当前会话涉及的文件差异 | 任务前已有改动与新增改动 |
| **产物与 Checkpoint** | 固定图表、报告和阶段状态 | 输入、版本、恢复位置 |
| **Evidence DAG / Dossier** | 审查主张与来源并生成科研交付 | 反证、限制、未验证项 |

## 工具使用原则

- 先确认顶部显示的工作区位置。
- 终端命令必须说明将读取和写入什么。
- 浏览器下载、账号登录和表单提交属于外部影响。
- Computer Use 中的发送、授权、删除和付款等动作应由用户确认。
- 工具结果应回到会话中解释，不能只保留一段无法定位的原始输出。
