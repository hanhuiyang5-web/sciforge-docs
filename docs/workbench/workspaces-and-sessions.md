# 工作区与会话

工作区决定 Agent 在哪里读取文件、查看 Git 和运行命令；会话保存围绕一个目标的消息、执行与结果。同一个工作区可以有多个会话。

## 打开工作区

1. 在工作区位置菜单中选择 **本地工作区** 或已经配置的远程目标。
2. 选择论文、代码或数据所在目录。
3. 核对左侧项目名称和顶部位置状态。
4. 新目标使用新会话；继续同一目标时沿用原会话。

![SciForge 新建会话界面](/img/docs/quickstart/quickstart-new-session.jpg)
*图 1：左侧组织工作区和历史会话，中间区域用于开始新任务。*

## 查看和引用文件

从顶部工具栏打开 **文件** 面板，展开目录并预览文件。需要 Agent 重点读取某个文件或目录时，使用页面提供的引用操作，而不是把大段内容复制到提示词中。

![SciForge 工作区文件面板](/img/docs/guides/workspace-files.jpg)
*图 2：文件面板显示当前工作区内容，并可将对象加入当前任务上下文。*

## 管理会话

- 点击会话名称继续之前的目标
- 使用搜索查找历史会话
- 归档暂时不需要的会话，并从归档列表恢复
- 删除前先确认重要结果已经保存到工作区或科研记录
- 不要用一个超长会话混合互不相关的科研目标

## 核对文件变更

写入型任务结束后，打开 **变更**：

1. 确认本次会话涉及哪些文件。
2. 打开差异，逐行核对新增、删除和修改。
3. 区分任务新改动与任务前已有的工作区状态。
4. 需要修正时，在原会话中引用具体文件和问题。

![SciForge 变更面板](/img/docs/guides/workspace-changes.jpg)
*图 3：变更面板用于审查会话修改；项目级 Git 状态仍应独立检查。*
